# Jack — Mathematics AI Expert

Jack is an advanced Mathematics AI built for people who don't want to talk to math like a calculator.

You can type math normally, ask questions casually, use symbols, mix words with expressions, or throw in some Gen-Z energy.

**You type it. Jack gets it.**

## YO, GO TALK TO JACK

You can literally start with:

```text
hello
hey jack
how are you?
what can you do?
```

Then switch straight into math:

```text
yo what's 45 + 55?
bro what's √144?
wait calculate 2sin(30)
ok what's sin 45 plus cos 45?
```

No need to change the way you talk just because you're doing math.

## JACK GETS THE VIBE

Jack is designed to understand different ways of asking the same thing.

```text
√25

square root of 25

what's the square root of 25?

yo what's √25?

can you get me the square root of 25?
```

Same math.

Different wording.

**Jack gets what you're asking.**

## OKAYYY, BUT CAN JACK ACTUALLY MATH?

Yeah.

Jack can handle mathematical expressions including:

```text
56 + 24
√16
square root of 25
2sin(30)
sin²(30)
sin 45 + cos 45
100 / 5
25 × 4
```

And it can understand natural-language versions too.

```text
what is 25 plus 30?
what's 50% of 200?
yo calculate 45 times 12
bro what's the square root of 81?
```

## WAIT... YOU CAN KEEP TALKING?

Yep.

You can continue the calculation instead of starting from zero every time.

```text
56
- 6
× 2
+ 10
```

Jack can understand the flow of the calculation and keep up with the conversation.

## NO BORING CALCULATOR ENERGY

It's not just:

**type → answer → done**

**talk → Jack understands → calculate → keep going**
